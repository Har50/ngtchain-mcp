NGT Chain MCP privacy

This page is only about the NGT Chain MCP server (@ngtchain/mcp) and the Claude Code plugin in this repository. It is not the privacy policy for the NGT Chain website or for any paid API you choose to call.

The operator is Plavena (proprietorship of Harsh Dhillon).

Agent key

The agent wallet private key is a setting on this computer. In Claude Code it is a sensitive plugin setting. In the desktop extension it is a setting of that extension. It stays on this computer. The server uses it on this computer to sign payments. It is not sent to NGT Chain, to a paid API, or to the local dashboard. The Claude Code plugin does not read the key from an existing environment variable.

What it contacts

  • The paid API. pay_and_fetch calls the HTTPS address you ask for. fetch_ngt_stream calls https://www.ngtchain.com/v1/agent/stream.
  • A Base RPC. The server reads the agent wallet's NGT and USDC balances from Base. With no custom RPC set, that is the public Base mainnet RPC.
  • The local dashboard. npx @ngtchain/mcp dashboard serves a page on 127.0.0.1 on this computer only. It is not reachable from other machines. The funding page opened by fund_agent_wallet is also only on this computer.

Payments

A payment is a transfer of NGT or USDC on Base. The agent wallet address, the amount, and the recipient are public on Base. The server does not hide them.

Each call spends real NGT or USDC from a wallet you fund. fetch_ngt_stream is a real payment of 0.001 NGT, not a test. USDC stays off until you set a USDC per-call cap and a USDC session budget. The money protection is the per-call cap (max_price) and the session budget (session_budget). A destructive hint on a tool is only a hint. The server does not show a spend-confirmation dialog.

Analytics

The server has no analytics. It does not send usage data to NGT Chain.

A log on this computer (~/.ngtchain/activity.jsonl) records the time, host, outcome, amount, and Base transaction of a call. It does not record the agent key, request headers, query strings, or response bodies.
